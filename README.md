## The review

> The sun shines straight into my eyes every morning and clocks off before I finish work. One star. Terrible opening hours.

A deadpan one-star review of the sun: the everyday essential with the worst opening hours in the business. It is in your eyes before you have had coffee, and it has already gone home by the time you finish work.

## How it works

`main.py` (Python 3.13, standard library only) writes the review as a single line to `/output/entry.txt`. The review is 121 characters, inside the 160-character limit.

Run it with:

```sh
python3 main.py
```
